# Design source

`prototype-design-system/` is the Claude Design prototype this UI was built from (`.dc.html` files plus `support.js`, its runtime):

- `PayrollKit Design System.dc.html`: tokens and component sheet
- `PayrollKit.dc.html`: the clickable prototype (login, dashboard, runs, run detail, payslip drawer, self-service)
- `PayrollKit Screens.dc.html`: every screen in light and dark, desktop and 390px
- `PkRun`, `PkPayslip`, `PkPeople`, `PkSetup`, `PkAudit`: screen components

Open them in a browser to click through. They are reference material only and are not part of the build.
