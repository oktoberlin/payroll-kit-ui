Rules that matter

  • Money is rendered exactly as the API string. Never parse to float. Two decimals, thousands separators, $ only in column headers and totals.
  • Every money and ID cell is font-mono tabular-nums text-right.
  • Status = dot + word (+ lock for Paid). Colour is never the only signal.
  • Emerald is reserved for Paid / success. Amber = Draft / warning. Indigo = Approved / primary. Rose = errors.
  • Disabled actions use aria-disabled so they stay focusable and can show a tooltip ("Admin only").
  • Irreversible actions (Approve, Mark paid) open a confirm dialog that states the consequence.
  • Rows 40px (36px compact), hairline dividers, no zebra, sticky header, pinned totals row.
